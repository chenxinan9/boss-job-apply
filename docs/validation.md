# 验证范围

v0.4.0-rc.8为未验收开发候选。配置/打包/快照保护测试只证明对应代码范围，不证明BOSS实站发送。

| 项目 | 当前证据边界 |
|---|---|
| 原本地Codex | 历史有平台当天满额；当前生产修复不代表公开包已验收 |
| 本版公开Codex | 前置引导与同页循环、派发记录、无默认截止已对齐；尚未全新机器独立验收 |
| 本版WorkBuddy macOS | 本机官方浏览器能力入口已观察；本版独立真实发送、持续执行未验收 |
| 本版WorkBuddy Windows | 未实机验收 |
| 下载、解包、配置和可选快照保护 | 以CI及回下载核对实际结果为准，不登录BOSS、不算投递通过 |

真实验收须客户端自己公开下载、保留本人资料、完成前置引导、接管本人已登录页、真实首次沟通并继续后续岗位。维护者代点、手动发送、截图、模拟招聘页或点击数不能替代。满额只认当天平台明确提示，已满当天不能试新发送。跨机器、账号和长时间稳定性尚未证明。

旧技术证据见仓库docs/history；不将旧工具或历史成功当本版通过。私人简历、聊天、截图、Cookie与派发记录不得公开。
