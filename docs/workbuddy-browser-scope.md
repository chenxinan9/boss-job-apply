# WorkBuddy候选边界

两系统包各三文件，业务正文一致。使用当前实际可用、已正常授权的腾讯官方browser-use或computer-use，复用本人已登录原窗口；不把浏览器扩展作为唯一前置，不默认要求录屏，不安装第三方代理或独立浏览器。匹配由主模型完成，官方GUI任务仅负责有明确边界的页面读取或一次已批准动作，不能独自决定整批投递。模型免费与GUI能力费用分别核对，已授予权限复用。

实际诊断发现：browser-use只列出内置浏览器时，另一已启用的官方computer-use仍能列出原BOSS窗口。旧包却强制前者并禁止后者，使执行停在反复连接引导。现已修正这一约束冲突；窗口可见仍不证明登录、JD可读或真实发送。不能用配置里的目标、模型自述、下载或工具连接证明满额。

候选尚无本版独立真实发送和持续投递证据，Windows未实机验收。旧发行不作为执行入口；本人已完成的准备保留复用，同版不重复下载，换版先保护私人资料并移除确认旧包执行文件。
