# 来源与范围

本项目由使用者授权，将实际使用的 Codex / WorkBuddy BOSS 首次沟通方法整理为通用包。文档、配置校验及 Codex 可选原生快照保护代码按 MIT 发布。

公开版本移除了私人资料、机器路径、原任务/自动化标识、浏览器空间编号、招聘者对话和运行日志。Codex 可选模块从原流程提取新鲜快照与单次点击保护，移除旧复制岗位链接、旧台账、旧回执事务及作者控制锁实现；它是经过单元测试的通用改编，不是假称原环境逐字复制后即完成新机器验收。

BOSS、Codex、WorkBuddy、Chrome、Ego 的商标、软件和服务属于各自权利人。本项目不包含其实现、账号或客户端分发文件，也不声称与其存在官方合作。WorkBuddy官方接入以当前客户端设置和它提供的扩展入口为准；接口以使用者安装版本文档为准。

公开测试只包含人工构造的最小函数输入，不包含模拟招聘站，也不把单元检查称作真实投递成功。两个WorkBuddy系统包业务规则一致；Codex保留配置模板与可选代码。本人条件只读自己的私有资料，不加入作者背景。旧接入证据保留在history，不能当成当前版本验收。
