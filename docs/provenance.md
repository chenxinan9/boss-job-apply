# 来源与边界

项目将用户授权的BOSS同页首次沟通方法整理为通用说明。已跑通的本机Codex是行为对照，不等于公开包的运行证据。当前只维护源码审计候选，不提供已验收通用安装包。

已删除可选原生AX适配器：其旧格式约束会拒绝当前合法原生快照，而且从未是通用客户端的已验收运行入口。新鲜状态、当前JD、单次沟通和不重试仍由执行手册要求；不再为可选包装引入Node依赖。

公开源码不含个人简历、求职条件、机器路径、固定任务、浏览器空间、聊天、Cookie或运行截图。旧错误接入只在Git历史追溯。BOSS、Codex、WorkBuddy和浏览器实现属于各自权利人；本项目不分发其客户端、驱动或登录状态。
