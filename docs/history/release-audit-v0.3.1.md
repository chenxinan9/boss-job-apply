## 复核采用的范围

按一个使用者、一个 BOSS 账号、一个活动执行者审查，从下载、独立解包、私有配置、工具选择、同页检查、岗位判断到本人授权后的单次沟通。没有加入数据库、外发服务、作者职业条件或逐岗台账。

下载器在解压之前强制校验发布哈希，解包时检查路径、类型、大小和内容完整性，已有目标目录拒绝覆盖。它是下载前的入口，不放入待下载 ZIP 内做循环校验；SHA256SUMS 无字节数不代表无法校验完整性。相关实现及失败测试见 `tools/download_release.py` 和 `tests/test_download_release.py`。

`SKILL.md` 与执行手册均要求先读 `references/browser-session.md`；登录遮层、验证后原页读取和截图失败不重复的规则位于该必读文件及接入说明中。审计未将同一句话没有复制到每个文件判成缺失。工作区私有文件忽略和旧条件映射由客户端按说明完成；不会将某个使用者的旧字段和职业门槛固化成公开模板。
