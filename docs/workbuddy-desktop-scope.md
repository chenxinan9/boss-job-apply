# WorkBuddy 电脑界面版：开发范围与验收

2026-10-15 按用户最新要求收窄。目标为 Windows WorkBuddy + 系统 Edge，以及 macOS WorkBuddy + 系统 Safari；本人明确指定的已安装浏览器可沿用。不安装浏览器，不复制登录状态，不通过换浏览器处理已有验证阻断。

两个独立技能入口放在 `packages/boss-apply-workbuddy-windows/` 与 `packages/boss-apply-workbuddy-macos/`，各只需 SKILL.md 与 LICENSE。业务流程一致，系统能力说明不同。模型按画面和简历自主判断，保留硬条件、单次沟通、授权和真实停止边界；不打包新的驱动、数据库、浏览器接入脚本或固定坐标。

## 当前能力证据

- 本机 WorkBuddy 5.7.7 随附的 ComputerUse 实现说明为 macOS 桌面截图与鼠标键盘；启用判断包含 `if (!isDarwin()) return false`，还需产品开关。静态实现存在不等于工具已向当前任务开放，更不代表权限已就绪。本次只读查实现，未修改应用或绕过平台判断。
- 这仅是本机 macOS 构建的证据，不能据此声称所有 Windows 版本没有电脑操作功能。Windows 当前版本的实际工具与系统 Edge 尚未实机核对。
- 本机 Codex 原生电脑操作已成功，不等于 WorkBuddy 原生路径成功；此前 WorkBuddy 的 Ego 结果也不能作为这两个候选的成绩。

## 交付门槛

每个系统分别完成：由该系统上的 WorkBuddy 自行取得候选；保留真实个人条件；用实际可用的电脑操作工具观察系统浏览器；本人完成必要登录；选择卡片并读取对应 JD；按授权真实首次沟通后继续处理后续岗位。维护者只观察，不补步骤、代点或改候选工作区。

失败先区分缺工具、权限、窗口选择、读取点击错误和平台验证。缺工具不能靠新增说明或换浏览器掩盖。公开包实际版本与验证版本必须一致；修复后重新验收。首次成功、连续执行与满额分别报告。

## 当前交付状态

两份均为 v0.4.0-rc.1 未验收预发行候选，供独立实测；不覆盖 v0.3.4 资产，不作为给普通使用者的可用版本推荐。Windows 缺实际测试环境与工具能力证据；macOS 缺 WorkBuddy 原生工具实际调用、Safari 切岗和真实发送证据。仅文件检查通过时不能发布为可用版。

原 Codex 生产流程和个人资料不在本次改动范围；旧浏览器适配代码暂留原位用于已有版本追溯，不再作为这两个候选的后备执行路径。
