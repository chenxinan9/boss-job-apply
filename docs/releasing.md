# 发布要求

当前v0.4.0-rc.13只作为标有prerelease的独立测试候选。不得标为Latest稳定版或将下载、离线测试、CI、连接与本机参考成绩写成公开包实站通过。默认下载关闭；只有--candidate明确选择固定候选，RELEASE_AVAILABLE仍为false。

发布前按tools/package-manifest.json白名单打包，核对源码、ZIP内容、SHA256SUMS、隐私与测试。只包含通用流程，不含私人简历、条件、账号、Cookie、聊天、截图、日志、路径或任务标识。固定版本发布后须回下载核对；候选也要通过三系统下载和解包检查。

对应客户端必须自己公开下载、保留本人资料、完成引导、接管本人已登录原页、真实首次沟通并继续处理，才能据实标注已观察范围。首次发送、持续处理、当天平台满额分别报告；Windows单独实机验证。维护者代点、途中喂点击步骤或修改验收配置不算独立通过。轮流对照只是调度业务批次，不替客户端完成操作。

实站通过后才决定是否发布稳定版和开放默认下载。MIT不包含第三方客户端实现、权限或商标授权。旧Git历史仅追溯，不是运行入口。
