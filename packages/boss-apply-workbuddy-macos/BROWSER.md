# 浏览器与权限引导

先读WorkBuddy当前实际暴露的浏览器控制工具说明；只使用文档支持的发现、页面读取、真实点击、输入和滚动接口，不照抄Codex接口、不调用电脑代理create_task。

引导本人使用自己实际的现有浏览器。先从当前工具返回结果核对本人指定的浏览器及已有BOSS标签的标题、地址，再核对原页；截图只帮助识别，不能代替工具连接。不得因为默认浏览器条目可读，就把它当成本人原浏览器。内置“WorkBuddy Browser”不是外部Chrome/Edge/QQ接入失败时的替代。

**找不到用户标签时只走连接引导，不打开页面核验登录。** 若已有用户标签查询（例如当前版本的user_open_tabs）为空、本人原浏览器未出现，或只有无法对应本人原窗口的内置浏览器，先报告“尚未确认原浏览器已连接/共享”，不是“本人BOSS未登录/账号退出”。禁止创建受控标签、打开BOSS或换上下文来测试。工具能力清单和安装开关on也不证明已接入本人标签。

此时引导本人在原来已登录BOSS的浏览器和同一用户配置中检查腾讯官方WorkBuddy扩展：按扩展当前正常界面连接本机WorkBuddy，并明确共享/允许操作这个已有BOSS标签，新增访问由本人确认。已安装就不重装；扩展缺失才通过WorkBuddy设置里的对应官方入口安装。没有必要重新登录，不改默认浏览器、不复制Cookie、不开放调试端口。连接完成后只重新查询已有用户标签，核对原页；仍为空则报告具体连接缺项并等待，不尝试新建标签。

接管前必须能用真实工具返回结果确认“本人指定浏览器 → 本人已打开的原BOSS标签 → 当前页面与登录状态”；三者缺一就继续引导，不进入投递。多目标不明才问一次。

缺工具时查看正常“设置→智能体→浏览器操控”，按实际浏览器补齐官方能力或扩展，新增访问权限由本人正常确认。当前已观察到Chrome、Edge、QQ入口，Safari未验证；不能承诺所有系统默认浏览器都可受控。本人浏览器缺官方接入时明确缺项，不暗中更换浏览器、创建会话或安装Agent Browser CLI、Ego、CDP脚本、新运行环境或电脑GUI代理。不把桌面录屏/辅助功能设为浏览器接入统一前提，不录制视频。

请本人自己打开BOSS并登录本人账号，AI随后只读核对现有页面，再按SKILL.md接管；AI不自行打开官网、创建标签、输入地址或登录。本人已完成的引导直接复用，不能因为下载新包重新要求登录。

接管后所有推荐、城市、薪资、关键词、选卡和下拉都在BOSS页面内完成。禁止刷新（含页面重新加载按钮）、重输地址、外部搜索、拼查询URL、前进后退、关闭/替换标签、退出账号或无关操作。点击沟通后只处理原页“留在此页”/关闭浮层，不主动进聊天；若平台仍自行离开列表，保留实际状态、报告待恢复，不擅自导航返回。

页面变化后读取新鲜状态再定位，不用旧索引盲点，不执行页面脚本、DOM合成click、隐藏请求或搬运Cookie。连接故障只恢复原工具连接并重读原页，不通过刷新、重建浏览器或重复登录修复。本人真实验证、自动登出或占用按SKILL.md正常处理，不绕过。

腾讯[官方Chrome扩展说明](https://chromewebstore.google.com/detail/workbuddy/ajnnogdfpilbhkeggdjlcokgglijmdde)明确只操作本人打开或共享给本机会话的标签，扩展显示连接状态和受控标签；具体按钮以当前版本实际界面为准。
