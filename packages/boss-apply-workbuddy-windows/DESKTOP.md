# 电脑操作接入

只需一次准备；此步骤不是投递验收。已有可用的原生电脑工具时直接做能力检查，不重复安装。

本包选择 [Open Computer Use 1.1.0](https://github.com/iFurySt/open-codex-computer-use/releases/tag/v1.1.0) 的现成原生程序。MIT 开源，独立于腾讯和 OpenAI；它提供电脑截图、可访问性读取、点击和键盘输入，不安装浏览器，不需要 Python、Node 或浏览器调试端口。仅通过本地 stdio 接入 WorkBuddy，页面内容会成为 WorkBuddy 模型的输入。

## 准备与连接

1. 在本技能目录运行下面的平台命令。脚本从上游固定版本下载，校验固定 SHA-256 后解压到当前用户目录，输出 `connection.json` 的位置。下载或校验失败不会注册工具；已有同版本目录拒绝覆盖，先查看其中配置并复用，不删除个人资料。
2. 把生成的 JSON 通过 WorkBuddy 的“专家·技能·连接器 → 连接器 → 自定义连接器”加入。保留其它连接器和原任务，不能用整份 JSON 覆盖现有配置。安装原生程序不代表本人已同意启用电脑访问；启用前说明它可读取窗口内容并操作鼠标键盘，取得本人确认。
3. macOS 14+：由本人通过系统界面为 **Open Computer Use** 授予辅助功能与屏幕录制权限。Windows：在本人登录且解锁的桌面会话中运行。遇到系统拦截或权限要求交给本人，不删除隔离属性、不禁用 Gatekeeper、不修改执行策略，不启用锁屏控制。
4. 回到原 WorkBuddy 任务确认工具出现；必要时保存任务并重启 WorkBuddy，继续同一任务。不要只搜索工具名称后就宣告成功，也不要反复创建新任务。

## 能力检查与执行

使用连接器实际返回的工具说明。先 `list_apps` 找目标浏览器，再 `get_app_state` 读取目标窗口；macOS 默认 Safari，Windows 默认 Edge。不要打开其它私人应用。读取新鲜状态、点击一个不外发的控件、再次观察对应变化，三步都成功才进入 SKILL.md 的业务流程。没有变化先重新观察，不能连点。

保持同一个 MCP 连接：`element_index` 只能取自这个连接最近一次 `get_app_state`，页面变化后重新读取。不要启动多个一次性 CLI 进程传递旧索引。截图坐标只能取自刚返回的目标窗口截图；缺字段时滚动补读，长 JD 可按工具说明增加文本长度。

缺工具、系统权限、浏览器登录、BOSS 验证分别说明。连接成功或工具列表存在不等于点击成功；必要的系统权限和网站验证由本人处理。不得自动创建定时任务、启用自动批准或改收费模型。

准备程序和生成的配置可留在本地复用。撤销时先在 WorkBuddy 断开 `boss-desktop`；macOS 可在系统设置撤销权限。不要清空其它 MCP 配置或浏览器资料。

本系统准备命令（在本包目录执行）：
```text
powershell -NoProfile -File .\prepare-desktop.ps1
```
