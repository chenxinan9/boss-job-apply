# 浏览器与权限引导

先读WorkBuddy当前实际暴露的浏览器控制工具说明；只使用文档支持的发现、页面读取、真实点击、输入和滚动接口，不照抄Codex接口、不调用电脑代理create_task。

引导本人使用自己实际的现有浏览器。通过本人指定或含标题栏、地址栏和BOSS页头的截图识别，再核对工具实际选中的同一标签。多目标仍无法确定才问一次；工具只能控制本人正常授权/共享的标签，另一窗口已登录不能证明本标签已登录。

缺工具时查看正常“设置→智能体→浏览器操控”，按实际浏览器补齐官方能力或扩展，新增访问权限由本人正常确认。当前已观察到Chrome、Edge、QQ入口，Safari未验证；不能承诺所有系统默认浏览器都可受控。本人浏览器缺官方接入时明确缺项，不暗中更换浏览器、创建会话或安装Agent Browser CLI、Ego、CDP脚本、新运行环境或电脑GUI代理。不把桌面录屏/辅助功能设为浏览器接入统一前提，不录制视频。

请本人自己打开BOSS并登录本人账号，AI随后只读核对现有页面，再按SKILL.md接管；AI不自行打开官网、创建标签、输入地址或登录。本人已完成的引导直接复用，不能因为下载新包重新要求登录。

接管后所有推荐、城市、薪资、关键词、选卡和下拉都在BOSS页面内完成。禁止刷新（含页面重新加载按钮）、重输地址、外部搜索、拼查询URL、前进后退、关闭/替换标签、退出账号或无关操作。点击沟通后只处理原页“留在此页”/关闭浮层，不主动进聊天；若平台仍自行离开列表，保留实际状态、报告待恢复，不擅自导航返回。

页面变化后读取新鲜状态再定位，不用旧索引盲点，不执行页面脚本、DOM合成click、隐藏请求或搬运Cookie。连接故障只恢复原工具连接并重读原页，不通过刷新、重建浏览器或重复登录修复。本人真实验证、自动登出或占用按SKILL.md正常处理，不绕过。
