# 浏览器与权限引导

先读WorkBuddy当前实际暴露的官方工具说明。复用已经能接入本人原窗口的能力：官方browser-use或已正常启用的腾讯官方computer-use均可，不把浏览器扩展当作所有机器的必备前置，不照抄Codex接口。不要安装第三方电脑代理、独立浏览器或驱动。

主模型负责读取完整JD、匹配本人条件及控制投递循环。若官方工具提供直接读取和原子操作，就按其文档使用；若只有create_task/continue_task，把官方GUI任务限于当前原窗口的读取或主模型明确批准的一次页面动作，不把整批筛选、评分和投递交给GUI子任务。读取任务须返回当前公司、岗位和完整JD；通过后才允许单次立即沟通。动作派发不明不重试；一个工具任务结束不等于本轮完成，下一动作仍由主模型依规则决定。先结束上一在途任务，不并发控制同一窗口。

检查当前模型能否读取该工具返回的图像；图像被过滤不能当作已看过截图，窗口标题也不证明登录态。可使用现有官方能力读取当前页面文字，不用猜数或安装OCR脚本。免费主模型不代表GUI能力免费；按本人费用边界核对，额外积分未经授权不得启动，不充值。已授权权限直接复用，不自动切“允许完全访问”或关闭确认；真正缺少的新增访问由本人正常确认。

引导本人使用自己实际的现有浏览器。先从当前工具返回结果核对本人指定的浏览器及已有BOSS标签的标题、地址，再核对原页；截图只帮助识别，不能代替工具连接。不得因为默认浏览器条目可读，就把它当成本人原浏览器。内置“WorkBuddy Browser”不是外部Chrome/Edge/QQ接入失败时的替代。

**找不到用户标签时先排查已有官方能力，不打开页面核验登录。** 用户标签查询为空或只有无法对应原窗口的内置浏览器，仅说明该入口未接到原页；不能断言本人未登录，也不能只重复查询就宣布排查完毕。核对当前官方工具说明、正常设置及已有原窗口；官方computer-use已能读取原页时直接复用，不再要求安装扩展或重复共享。只有窗口标题仍不足，接管前须读原页内容。禁止创建标签、打开BOSS或换上下文来测试。

使用browser-use且确需扩展时，才在原浏览器同一配置核对腾讯官方WorkBuddy扩展及其当前连接。已有授权范围内的正常连接排查由AI完成；本人已确认共享时先核实实际返回，不重复提出相同要求。已安装不重装；确实缺失才走WorkBuddy正常设置中的官方入口，新增访问由本人确认。没有必要重新登录，不改默认浏览器、不复制Cookie、不开放调试端口。两条官方路径均不可用时报告已经核实的具体缺项，不把猜测当作本人未授权。

接管前必须用真实工具返回结果确认“本人原浏览器窗口 → 已打开的BOSS页面 → 当前页面与登录状态”；不要求不同工具都提供标签ID。多窗口时根据实际页面内容选中原目标，不能让本人反复重登；目标仍不明才问一次。

缺工具时查看WorkBuddy正常设置中的官方能力，按当前版本说明核对浏览器操控或已安装的官方computer-use，不承诺所有系统浏览器均受支持。不暗中更换浏览器、创建会话或安装Agent Browser CLI、Ego、CDP脚本、新环境或第三方电脑代理。系统屏幕读取/辅助功能仅按当前实际工具需要核对，已授予就复用，不设为所有浏览器接入的统一前提，不录制视频。

请本人自己打开BOSS并登录本人账号，AI随后只读核对现有页面，再按SKILL.md接管；AI不自行打开官网、创建标签、输入地址或登录。本人已完成的引导直接复用，不能因为下载新包重新要求登录。

接管后所有推荐、城市、薪资、关键词、选卡和下拉都在BOSS页面内完成。禁止刷新（含页面重新加载按钮）、重输地址、外部搜索、拼查询URL、前进后退、关闭/替换标签、退出账号或无关操作。点击沟通后只处理原页“留在此页”/关闭浮层，不主动进聊天；若平台仍自行离开列表，保留实际状态、按下方窄范围恢复，不作其他导航。

页面变化后读取新鲜状态再定位，不用旧索引盲点，不执行页面脚本、DOM合成click、隐藏请求或搬运Cookie。连接故障只恢复原工具连接并重读原页，不通过刷新、重建浏览器或重复登录修复。本人真实验证、自动登出或占用按SKILL.md正常处理，不绕过。

腾讯[官方Chrome扩展说明](https://chromewebstore.google.com/detail/workbuddy/ajnnogdfpilbhkeggdjlcokgglijmdde)明确只操作本人打开或共享给本机会话的标签，扩展显示连接状态和受控标签；具体按钮以当前版本实际界面为准。

首次接管或无在途动作的同轮技术恢复时，可聚焦本人已存在的BOSS职位窗口；若原页为已登录的BOSS消息/公司页，仅可单击BOSS页头唯一同站“职位”进入原列表。需真实工具确认页头链接与账号，不能用省略URL或正文链接猜测。正常循环不得主动离开列表再借此返回，不用地址栏、刷新或新标签。技术恢复保留本轮组合位置、已派发公司岗位和数量；不读历史去重、不重置批次数、不重复补写记录。
