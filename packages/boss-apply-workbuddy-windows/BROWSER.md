# 连接本人实际浏览器

先读WorkBuddy当前实际提供的浏览器控制工具说明，直接使用其浏览器/标签发现和页面读取能力。不以“电脑应用操控”代替浏览器控制，不调用旧create_task电脑代理，不要求先授予桌面录屏或辅助功能权限，也不安装第三方MCP、Agent Browser CLI、Ego、CDP脚本或新的运行环境。

根据本人截图与实际浏览器列表选目标，再核对同一标签的地址、标题和内容。截图不能提供工具连接；工具只能控制用户实际授权或共享的标签，不能因为另一窗口已登录就推断本标签也已登录。本人已指定或已可靠识别目标时不换浏览器、不重复询问。没有已有BOSS页时，首次可打开一次https://www.zhipin.com/，之后让本人在此页登录并按SKILL.md核对。

当前任务没有浏览器控制工具时，查看WorkBuddy正常“设置→智能体→浏览器操控”。需要时仅通过这里安装或启用官方浏览器能力，并在正常入口为本人实际浏览器连接官方扩展；新增权限由本人在正常界面确认。已可用就直接复用，不重复安装。当前本机设置已观察到Chrome、Edge、QQ浏览器入口；Safari接入未验证，不能声称所有系统自带浏览器都能受控。若本人实际浏览器无可用官方接入，说明具体缺项并停在此处，不暗中换浏览器或退回电脑代理。

浏览器地址栏只用于首次打开BOSS官网；选城市、薪资、推荐标签和关键词均用BOSS页面控件。推荐组合先处理到底，再在BOSS“搜索职位、公司”输入框内搜索。不要让外部搜索引擎找岗位，不构造搜索URL、不让工具反复goto/open到岗位查询地址。

每次画面或页面变化后读取新鲜状态再定位。用浏览器工具实际返回的当前页面、可见文字或截图核实JD和按钮；不要执行页面脚本、DOM合成click或隐藏请求。只对BOSS站内当前页面逐岗交互，不打开其他私人应用或搬运Cookie、账号与浏览器配置。

保留一个实际执行者，不因扩展横幅或旧标题就断言另有执行者；真实干扰和用户暂停仍须停止。浏览器/页面读不到时报告准确失败动作，不让本人重复登录。费用按本人限制，主模型免费不替代工具费用提示；新增费用未经授权不批准。
