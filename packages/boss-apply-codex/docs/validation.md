# 验证范围

当前v0.4.0-rc.6为未验收开发候选。文件和回归检查只证明对应检查范围，不证明BOSS实站可发送。

| 项目 | 证据边界 |
|---|---|
| 维护者原Codex生产流程 | 已有平台当天满额证据；不等于公开包在新机器通过 |
| 当前公开Codex包 | 原可选模块保留，只补站内搜索限制；未在全新机器独立验收 |
| 当前WorkBuddy macOS包 | 正常界面已确认浏览器操控入口；本版独立真实发送未验收 |
| 当前WorkBuddy Windows包 | 尚未Windows实机验收 |
| 下载、解包、配置、可选模块回归 | 以对应CI实际结果为准，不登录BOSS，不算投递通过 |
| 新简历、长时间无人值守 | 未证明跨机器、账户和版本稳定 |

不能用模拟招聘页面、手工发送、维护者代点、截图或点击数冒充独立发送与满额。真实验收由客户端自己下载公开包，保留本人条件，用实际工具读取同页JD，获本人授权后首次发送并持续处理后续岗位。当天已满只能验证停止识别，不算新增发送。

旧技术证据保留在仓库docs/history；当前WorkBuddy流程见仓库docs/workbuddy-browser-scope.md。历史中曾成功的客户端、旧工具或只读动作不代表本版通过。公开不得上传简历、聊天、截图、Cookie或私有日志。
