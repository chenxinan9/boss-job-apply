# 同一页面与中断恢复

前置引导见setup.md。本人先打开并登录BOSS，AI只连接并读取该现有窗口/标签；根据本人指定、截图及工具实际窗口列表核对目标，多目标不明才问一次。没有现成已登录页就引导本人完成，不创建浏览器或标签代替。

接管后只在BOSS页面控件选择推荐、城市、薪资、卡片、关键词并滚动。每次页面变化重新读取新鲜状态，不用旧索引，不批选后统一发送。薪资等可见文字乱码时可读同页截图；仍读不准就按本人规则跳过，不请求隐藏接口或猜数。

不得刷新（含页面重载按钮）、地址栏输入、goto/open、新标签、前进后退、退出账号、清Cookie、重建profile或打开无关页面。外部搜索与拼岗位查询URL也禁止。点击立即沟通后留在原列表；提示挡住下一步时点当前可见“留在此页”，不进聊天补发或核验。平台意外离开列表时保留实际页面，按下方窄范围恢复；不作其他导航。

正常投递仅因平台当天明确满额、当前BOSS要求真实验证、本人账号自动退出或目标浏览器实际被占用而暂停；四项都只暂停动作并保留页面。本人暂停及权限/费用边界优先。别的标签标题、调试横幅、URL参数、空白或超时不能单独证明上述事件。

AI断线、工具连接错误、读取超时、普通加载是技术中断，不是任务完成。保留原页面和扫描位置，只按当前工具说明恢复同一连接、等待加载并重新读取原页，不刷新或重登。工具仍不可用时如实报告待恢复；恢复后继续下一未派发岗位，不重试刚派发或结果不明岗位。不为等恢复忙循环或另建执行者。

推荐某屏无匹配就下拉，某组按手册结束条件完成就下一组合；所有推荐完成才站内搜索。备选也暂时无匹配时保留进度等待新增或本人备选，不判完成、不放宽条件、不刷新重扫。任务没有默认运行时长和固定截止，跨日分开记录及核对当天额度。

只将必要的工具名称、失败动作和脱敏错误用于求助，不公开简历、聊天、截图、派发记录或登录数据。新版解压到新目录，保留原私人工作区、本人会话与原任务，不混旧执行说明，不现场编写投递程序。

首次接管或无在途动作的同轮技术恢复时，可聚焦本人已存在的BOSS职位窗口；若原页为已登录的BOSS消息/公司页，仅可单击BOSS页头唯一同站“职位”进入原列表。需真实工具确认页头链接与账号，不能用省略URL或正文链接猜测。正常循环不得主动离开列表再借此返回，不用地址栏、刷新或新标签。技术恢复保留本轮组合位置、已派发公司岗位和数量；不读历史去重、不重置批次数、不重复补写记录。
