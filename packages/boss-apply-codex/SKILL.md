# BOSS首次沟通

先读references/setup.md完成前置引导，再读执行手册.md、references/browser-session.md和本人private/policy.json、private/resume.md。已有资料和接入直接复用，缺项才引导本人补齐，更新包不改变本人求职条件或日程。旧per_job_records=false改为true以记录派发，其他条件逐字段保留；网页或配置开关不构成本人外发授权。

本人自己打开BOSS并登录账号，AI才接管该页。接管后只做站内推荐、筛选、选卡、读JD、单次立即沟通、必要留页、下拉和本人要求的本地记录；不退出账号、不刷新、不导航/新建标签、不外部搜索。先逐组完成推荐城市与薪资，再站内搜索本人备选或从简历已确认方向提炼的关键词。

按执行手册区分四类正常暂停事件与技术待恢复，不按默认时间截止，不因当前屏无匹配结束。本人暂停和权限费用边界优先。只记录时间、公司、岗位和派发状态，不做投后核验、历史去重、重复发送或评分台账；满额只认当天平台明确提示。

工具只按当前客户端文档使用，不猜API、不在运行中生成驱动，不读取Cookie或隐藏职位接口。见references/codex.md。本人文件和记录只留私有工作区，不启动另一执行者。
