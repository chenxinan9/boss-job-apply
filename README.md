# BOSS Job Apply

按本人简历和求职要求，在本人已打开、已登录的BOSS页面逐岗判断，单次立即沟通、留页并记录派发。先推荐城市薪资组合到底，再BOSS站内搜索。MIT开源。

**交付暂停：当前没有通过独立实站验收的通用安装包。旧发行包已下架，下载器已关闭。请勿向普通使用者推荐旧版本。** 本机Codex的历史成功不证明GitHub包、WorkBuddy或Windows已经跑通。

## 引导与执行

AI读取本人指定的简历和已确认条件，缺项集中询问；已完成的准备直接复用。本人在自己的浏览器打开BOSS并登录，AI再连接并核对这个原标签。缺少连接时引导正常授权或共享，空标签不等于账号退出；不另开页面验证登录。

已有本人投递授权后：推荐标签按本人顺序逐城市薪资组合处理；当前屏逐岗读取对应完整JD，按本人条件判断，合格只点一次立即沟通，必要留在此页并记录时间、公司、岗位、派发状态。当前屏无未处理有效匹配才下拉，真正到底才下一组合。推荐全部结束后才站内备选搜索；备选词可在那时依据本人简历与确认方向提炼，不强制预填。

不刷新、退出账号、地址栏或外部搜索、新标签、无关导航，不历史去重、不投后核验、不重试派发不明岗位。平台当天明确满额、真实验证、账号自动退出、实际占用时暂停动作；本人暂停和权限费用边界优先。技术断线保留原页待恢复，无默认截止。跨日分开记录，点击不算成功数。

私人资料、条件和记录只留本人的private/；更新保留资料与日程，不覆盖生产Codex，不自动创建定时或监督。

## 审查与打包

开发者可运行：`python3 tools/package.py`，再运行`python3 -m unittest discover -s tests -v`。这些检查不操作真实BOSS，也不证明投递通过。下载、解包的信任边界检查仍保留；关闭状态下下载器在联网前退出。
